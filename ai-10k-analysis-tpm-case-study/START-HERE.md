# Start Here

## 1. Create the GitHub Repository

1. Sign in to GitHub.
2. Select **New repository**.
3. Use this repository name:

```text
ai-10k-analysis-tpm-case-study
```

4. Add this description:

```text
Independent TPM portfolio case study for an AI-powered 10-K analysis platform.
```

5. Choose **Public**.
6. Do not initialize it with another README if you plan to upload this complete folder.
7. Create the repository.

## 2. Upload This Starter Package

After creating the repository:

1. Open the repository.
2. Select **Add file**.
3. Select **Upload files**.
4. Drag the files and folders from this package into GitHub.
5. Use this commit message:

```text
Add initial program charter and project README
```

6. Select **Commit changes**.

## 3. What to Do Next

Complete the portfolio in this order:

1. Requirements
2. Architecture diagram
3. Workstreams and milestones
4. RAID log
5. Decision log
6. API design
7. Security and data handling
8. Cost estimate
9. Monitoring plan
10. Launch-readiness checklist
11. Basic prototype

## 4. Accuracy Rule

Describe this as an **independent portfolio case study** until a working prototype exists.

Do not claim that you:

- Managed a staffed engineering team
- Launched a production AI platform
- Delivered this project for an employer
- Managed real customer funds or investment decisions through this platform
